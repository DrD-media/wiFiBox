# Пульт SoundBoxRadio

Готовый интерфейс обслуживает сервер на http://127.0.0.1:5000/.
Запуск проекта: `START_RADIO.cmd` в родительской папке.

После изменения исходников выполните `tools/build_web.cmd` из корня проекта.
Он вызывает локальные Node.js и Vite напрямую, без npm, установки пакетов и интернета.
Зависимости физически находятся в `frontend/node_modules`, Node.js — в `runtime/node`.

Проверка исходников из папки frontend:
`..\runtime\node\node.exe node_modules/eslint/bin/eslint.js .`

Пульт: музыка, микрофон, общий выход; у каждого громкость 0–100 и тишина.
Медиатека: редактирование треков, загрузка файлов, составление плейлистов.
Подключение: локальные IPv4, схема GPIO и инструкция настройки ESP32.
Прослушивание: `/debug/radio`, WAV поток того же эфира.
