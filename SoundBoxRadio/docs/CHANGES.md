# Что изменено и что проверять на плате

## Причины и исправления

1. Старые GPIO I2S не соответствовали фактическим проводам. Заданы LRCK=25, DIN=26, BCK=27 и стандартный I2S для FMT=GND на PCM5102A.
2. Поток унифицирован: 48 кГц, 16 бит, little-endian, стерео. Читаются только полные кадры по 3840 байт, TCP пакеты не считаются аудиокадрами.
3. При настоящем запуске обнаружены HTTP chunk-разделители, которые добавлял многопоточный Werkzeug даже в ответ на HTTP/1.0. В штатном запуске явно включена HTTP/1.0 выдача без chunk-разделителей. Приёмник проверяет заголовки и отказывается воспроизводить несовместимый поток.
4. Вместо жёсткого обрезания суммы источников добавлен связанный стереолимитер, независимые уровни, общий уровень и тишина. У микрофона фильтруются DC/гул, ресемплер хранит состояние между кадрами.
5. Для аналоговой пары PCM5102A/PAM8403 задан консервативный уровень −22 дБ. Это ограничивает вероятность перегрузки входа усилителя. Подтвердить аналоговую причину можно только прослушиванием и измерениями на устройстве.
6. Сетевое чтение и I2S разведены по задачам ESP32. Ограниченные очереди, предварительное заполнение, DMA, автоматическое переподключение и тишина при недостаче данных заменили воспроизведение произвольных пакетов.
7. Запуск больше не открывает vite.js через Windows Script Host, не вызывает системные npm/Python и не устанавливает пакеты. Весь рабочий runtime и средства сборки внутри проекта.
8. Плейлисты переключаются из фонового потока с Flask app context; устаревшее событие конца трека не переключает новый плейлист. Ошибки файлов/микрофона/формата возвращаются в интерфейс. Каталоги сохраняются атомарно.
9. Пульт переписан под одновременную музыку и микрофон: три регулятора, тишина, уровни, лимитер, выбор микрофона, остановка эфира, поиск в библиотеке и понятное подключение платы. Удалены старые дубли пульта, пустые вкладки и неиспользуемые интернет-интеграции.
10. Главная папка переименована в SoundBoxRadio; сервер — backend, пульт — frontend, прошивка — отдельная соседняя папка SoundBoxFirmware (бывшая Temper1). Медиа и пользовательский каталог сохранены.

## Автоматические проверки

- Модульные/API тесты: лимитер полной суммы без плоского обрезания, абсолютная тишина при нуле/отключении, независимые источники и слушатели, отбрасывание только целых кадров, непрерывность преобразования частоты микрофона, удаление DC, валидация управления и ошибок микрофона, реальный FFmpeg, безопасное сохранение каталога, фоновое переключение плейлиста.
- Настоящий автономный запуск через START_RADIO.cmd: пустой PATH, ложные системные PYTHONHOME/PYTHONPATH, блок внешних адресов и DNS. Два одновременных HTTP клиента читают PCM кусками по 997 байт; проверяются заголовки, темп, отсутствие chunk-разделителей, ненулевой сигнал и тишина после остановки.
- Реальный микрофон компьютера: открытие, совместная работа с музыкой, повторное открытие и освобождение устройства. Конкретный микрофон, длительность и измерения сохранены в validation.json.
- Интерфейс: ESLint и production сборка локальными инструментами. Визуальную проверку в браузере провести не удалось: модуль Computer Use не смог подключиться к native pipe. Она не считается пройденной.
- Прошивка: успешно собирается локальным PlatformIO/Arduino, оба бинарных образа сформированы. Сеть для сборки заблокирована в процессе PlatformIO.

## Аппаратная проверка остаётся

USB ESP32 на компьютере не обнаружен: доступны только виртуальные Bluetooth порты и COM1. Плату не прошивали, звук через PCM5102A/PAM8403 физически не прослушивали. Не заявлены измеренная задержка, устойчивость конкретной Wi-Fi сети или отсутствие аналогового хрипа.

После подключения платы:

1. Прошить ../SoundBoxFirmware/FLASH_ESP32.cmd, настроить локальную сеть, проверить музыку на малом уровне.
2. Убедиться, что один динамик получает оба канала и нет хрипа при увеличении уровня.
3. Одновременно включить микрофон; проверить отдельные громкости 0–100, тишину и красную кнопку.
4. Отключить/включить Wi-Fi и сервер: приёмник должен замолчать и восстановить поток. Счётчики недостачи буфера видны на веб-странице ESP32.
5. Проверить питание под нагрузкой и провести длительное прослушивание на месте установки. При слабом Wi-Fi можно увеличить PREBUFFER_FRAMES в ../SoundBoxFirmware/src/main.cpp ценой задержки.

Старое неиспользуемое окружение .venv оставлено, поскольку автоматическая проверка отклонила его удаление. Код на него не ссылается.

## Уточнение расположения прошивки

По указанию пользователя обновлена именно бывшая папка Temper1: теперь SoundBoxFirmware. Туда перенесены актуальные исходники, образы и средства сборки. Копии main из Temper1 удалены; прежние библиотеки и кэши изолированы в legacy из-за блокировки рекурсивного удаления. В SoundBoxRadio отдельной копии прошивки больше нет.
