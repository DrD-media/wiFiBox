# SoundBoxFirmware

Отдельный проект прошивки ESP32. Это прежняя папка **Temper1**, переименованная и обновлённая.
Сервер и пульт находятся рядом: `../SoundBoxRadio`. В сервере больше нет отдельной копии прошивки.

## Где что лежит

- **src/main.cpp** — единственный исходник приложения ESP32.
- **platformio.ini** — конфигурация ESP32 Dev Module / WROOM, Arduino, Espressif32 6.13.0.
- **dist/SoundBoxRadio-full.bin** — готовый полный образ для адреса **0x0**.
- **dist/SoundBoxRadio-app.bin** — приложение для адреса **0x10000**, без загрузчика.
- **dist/manifest.json** — контрольные суммы исходника и готовых образов.
- **runtime/python** — локальный Python для сборки и загрузки.
- **runtime/platformio/python** — PlatformIO, pyserial и зависимости.
- **runtime/platformio/packages/framework-arduinoespressif32** — Arduino ESP32 и штатные библиотеки WiFi, WebServer, Preferences, DNSServer.
- **runtime/platformio/packages/toolchain-xtensa-esp32** — компилятор.
- **tools/firmware.py** — единый обработчик сборки и загрузки.
- **legacy** — старые неиспользуемые библиотеки, архив lib.zip и кэши сборки Temper1. Автоматическая проверка отклонила их удаление; они не участвуют в новом проекте.

Старый ESP32-audioI2S заменён простым приёмом PCM и штатным I2S драйвером ESP32. FastLED, GyverMAX7219, EncButton и прочие старые внешние библиотеки не нужны для вашей схемы. Старые копии main и устаревшие скрипт загрузки/рабочее пространство удалены.

## Сборка и загрузка

1. **BUILD_FIRMWARE.cmd** — пересобрать оба образа. Всё находится внутри этой папки; системные Python, PlatformIO и интернет не нужны. Внешние обращения в процессе сборки заблокированы.
2. **FLASH_ESP32.cmd** — подключить ESP32 кабелем USB с передачей данных и выбрать номер устройства из списка. Можно запустить `FLASH_ESP32.cmd COM5`.
3. **LIST_PORTS.cmd** — показать доступные последовательные порты.

Открывайте **SoundBoxFirmware.code-workspace** в VS Code. Сборка Ctrl+Shift+B и задача «Прошить ESP32 через USB» также используют локальные инструменты. PlatformIO настроен на `runtime/platformio`, без абсолютных путей к чужим папкам и без фиксированного COM4.

Команда без паузы, удобная для проверки:
`runtime\python\python.exe -I -X utf8 tools\firmware.py --build`

После загрузки подключитесь к сети **SoundBoxRadio-Setup**, откройте **http://192.168.4.1**, задайте Wi-Fi, IPv4 компьютера с сервером и порт 5000. Прежние ключи настроек в NVS (namespace radio) сохранены. Если роутер выключен при старте, плата открывает настройку и продолжает пытаться вернуться к сохранённой сети.

## Ваша схема

| ESP32 | PCM5102A / элемент |
| --- | --- |
| GPIO25 | LCK / LRCK |
| GPIO26 | DIN |
| GPIO27 | BCK |
| GPIO13 | кнопка → GND |
| GPIO14 | LED через 330 Ом → GND |

PCM5102A: FMT, FLT, DEMP, SCK → GND; XSMT → 3.3 V. Питание 5 V с общей землёй. Выходы ЦАП R/G/L подключены к входам усилителя. Динамик между R+ и R− PAM8403.

Поток сервера: `/api/radio/stream`, 48 кГц, PCM s16le, стерео. Прошивка собирает целые кадры, проверяет заголовки, буферизует 120 мс перед стартом и переподключается при потере связи. I2S работает отдельно от сетевого чтения. На один динамик подаётся сумма левого и правого каналов с консервативным уменьшением уровня для PAM8403.

Кнопка GPIO13: нажатие — тишина; удержание 3 секунды — настройка Wi-Fi. Веб-страница ESP32 в рабочей сети показывает буфер и ошибки, позволяет изменить громкость и отключить звук.

## Проверка

После переноса необходимо успешно собрать проект из этой папки. Отчёт — `docs/validation.json`.
ESP32 пока не обнаружен по USB, физическую загрузку и звучание через ЦАП/усилитель не проверяли.
